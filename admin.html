📋 견적서 관리

ISO 9001 견적서 생성

접수된 신청서를 기반으로 ADJ_v.2.2 기준에 따른 견적서를 생성할 수 있습니다.

🎯 주요 기능

  • ADJ_v.2.2 기준 심사일수 자동 계산
  • 직원 수, 사업장 수, 업종별 복잡도 고려
  • 전문적인 Word 견적서 자동 생성
  • 견적서 데이터 자동 저장

📊 계산 기준

  • 기본 심사일수: MD5 기준
  • 심사비: 일당 1,450,000원
  • 제경비: 심사비의 10%
  • 업종별/복잡도별 추가 일수 적용
