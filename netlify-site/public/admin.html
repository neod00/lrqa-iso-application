🎯 주요 기능

  • ADJ_v.2.2 기준 심사일수 자동 계산
  • 직원 수, 사업장 수, 업종별 복잡도 고려

📊 계산 기준

  • 기본 심사일수: MD5 기준

  • 제경비: 심사비의 10%
  • 업종별/복잡도별 추가 일수 적용
